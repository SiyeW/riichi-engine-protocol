# 参考决策引擎

这是一个只依赖 Python 标准库的 `decision-v1` 最小实现，用于验证第三方引擎包、
合法候选动作和状态通知链路。它不具备麻将棋力，不应参与真实分析。

## 构建

在本目录打开 PowerShell，使用安装了 PyInstaller 的 Python 执行：

```powershell
.\build.ps1
```

构建完成后：

1. 将本目录复制到任意长期保存的位置。
2. 在“引擎管理”中添加配置，选择 `runtime\mock-engine.exe` 作为引擎文件。
3. 选择同一目录中的 `model.bin` 作为权重文件，然后点击加载。

程序不会经 Shell 启动引擎；`engine.json` 指向构建生成的
`runtime\mock-engine.exe`。

## 行为

参考引擎为每个合法候选生成确定性的原始值和 Softmax 概率，选择最后一个候选。
它实现握手、初始化、状态查询、分析、会话重置、重新加载和关闭，可用于检查：

- 多会话请求是否隔离；
- 宿主是否只发送合法动作；
- 状态灯能否反映加载、运行和错误；
- 权重摘要变化后缓存是否失效。
